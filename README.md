# 🚀 Dealora Landing Page

**Dealora Landing Page** es una página de aterrizaje profesional y responsive diseñada para presentar la aplicación móvil **Dealora**, una plataforma de cupones y descuentos que conecta usuarios con establecimientos locales.  
El sitio está optimizado para conversiones y diseñado para captar tanto **usuarios finales** como **establecimientos interesados en unirse a la plataforma**.

---

## 🎯 Objetivos Principales

- Generar lista de espera antes del lanzamiento oficial  
- Captar establecimientos interesados en ser socios  
- Explicar el valor de la aplicación de forma clara  
- Optimizar conversiones con diseño persuasivo

## 📱 Secciones y Componentes

### 1. Hero Section  
- **Propósito:** Captar atención inmediata  
- **Componentes:** Headline, subheadline, CTAs, stats  
- **Técnicas:** Gradient text, animated mockup  

### 2. Benefits Grid  
- **Estructura:** 3-column responsive grid  
- **Animaciones:** Hover effects, scale transitions  
- **Iconos:** Emojis nativos (performance)  

### 3. How-it-works  
- **Diseño:** Timeline visual con números  
- **Responsive:** Stack en mobile, inline en desktop  

### 4. Categories Showcase  
- **Grid:** 4-column (desktop), 2-column (tablet), 1-column (mobile)  
- **Efectos:** Card hovers, gradient backgrounds  

### 5. Business Section  
- **Target:** Establecimientos/comercios  
- **Elementos:** Value proposition, benefits list, CTA  

### 6. Waitlist Form  
- **Campos:** Nombre, email, tipo de usuario  
- **Validación:** Client-side + submission handling
