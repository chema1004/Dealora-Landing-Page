# 📌 Dealora – Tus cupones favoritos en un solo lugar  
 

**Dealora** es una página web diseñada para mostrar y promocionar una futura aplicación de cupones de descuento. Conecta a usuarios con experiencias locales en **restaurantes, belleza, fitness y entretenimiento**, ofreciendo hasta un **70% de ahorro**.  

---

## 🚀 Características principales  

- ✅ **Diseño responsivo** con **Tailwind CSS**.  
- ✅ **Menú adaptativo** (desktop y mobile).  
- ✅ **Secciones principales**:  
  - Hero con CTA.  
  - Beneficios destacados.  
  - Cómo funciona (3 pasos).  
  - Categorías interactivas.  
  - Información para empresas.  
  - Formulario de lista de espera.  
  - Preguntas frecuentes (FAQ).  
  - Footer con enlaces y contacto.  
- ✅ **Interfaz moderna y minimalista** con gradientes y animaciones suaves.  
- ✅ **Formulario de lista de espera** con campos de nombre, email y tipo de usuario.  
- ✅ Uso de **Google Fonts** (`Inter` y `Playfair Display`) para tipografía elegante.  

---

## 🛠️ Tecnologías utilizadas  

- **HTML5** – estructura del proyecto.  
- **Tailwind CSS** – estilos rápidos y responsivos.  
- **JavaScript (básico)** – interacción en menú y FAQ.  
- **Google Fonts** – tipografía personalizada.  
- **Favicon e imágenes** – personalización visual.  

---

## 🔧 Instalación y uso  

1. Clonar el repositorio:  
   ```bash
   git clone https://github.com/usuario/dealora-landing.git
````

2. Abrir el archivo `index.html` en tu navegador favorito.
3. Personalizar imágenes, íconos y estilos en la carpeta `css/` y `images/`.
